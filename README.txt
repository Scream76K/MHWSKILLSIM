主な修正:
- 巨戟アーティアの「攻撃激化 / 会心激化 / 属性激化」を正しい固定値で分離。

- 復元ボーナスを生産・変異ボーナスと混同せず、一度だけ加算。

- 発動スキルを「通常 / シリーズ / グループ」に分離表示。
- モンスターの特殊個体variantに対応し、歴戦王アルシュベルド（★10）を追加。
- モンスター部位名を日本語表示に統一。
- キャッシュキーをv44に更新。

データはMHDB APIの最新取得を前提とします。「最新データを取得 / 更新」を押してください。
