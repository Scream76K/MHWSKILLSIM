MH Wilds スキルシミュレータ v1.4（iPhone / Safari向け）

機能:
- MHDB APIからスキル・防具・装飾品・護石・シリーズ・武器データを取得して端末にキャッシュ
- 必須/追加スキルから装備候補を検索
- 武器・防具・護石・装飾品の構成表示
- 1ヒット期待ダメージの概算
- 複数攻撃を登録してコンボ総ダメージ、理論DPS、実戦DPS、1分間期待ダメージを計算

DPSは「各攻撃の期待ダメージ×ヒット数」を合計し、コンボ時間で割り、さらに攻撃稼働率を掛ける方式です。実戦DPSはモンスターの行動、位置取り、回避、研ぎ、スタミナ等を自動再現するものではありません。

GitHub Pagesでは、index.html / manifest.webmanifest / sw.js / README.txt をリポジトリのルートに置いてください。
