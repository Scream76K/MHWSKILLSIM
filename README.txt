MH Wilds ビルド＆火力シミュレーター v4.14

v4.14 改善点
- 防具・護石・武器の全装飾品スロット候補を「付与最大Lvの高い順 → 50音順」で強制統一。スロットサイズは同順位判定に使用しない。
- 装飾品データの skills が配列／オブジェクトのどちらでも最大Lvを正しく抽出して並び替え。
- 最大会心率の計算土台を「計算済みの現在会心率」に統一。アーティア基礎会心、生産・復元会心の二重計上／取りこぼしを防止。
- 弱点特効など条件付き会心は最大会心率側だけに加算し、現在会心率とは分離。
- Service Worker キャッシュキーを v414 に更新。

GitHub Pagesへは index.html / manifest.webmanifest / sw.js / README.txt を同じ階層に配置してください。
