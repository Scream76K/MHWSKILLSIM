MH Wilds ビルド＆火力シミュレーター v4.23

珠選択UIの並び順を修正。

対象：
- 防具を選択した後の各スロットの珠選択欄
- 護石の防具スロット／武器スロットの珠選択欄

並び順：
1. 珠そのもののレベル（装飾品の slot）を降順：Lv3 → Lv2 → Lv1
2. 同じ珠Lvなら珠の名称を50音順

注意：
- 珠名末尾の【1】【2】【3】は装着可能スロットLvを表す。
- これは珠が付与するスキルLvとは別物。
- スロットLvは「そのスロットに装着可能か」の判定にも使用する。
- 並び順ではスキルLv・レア度・IDを使用しない。

実装：
- 防具／護石／武器の珠選択は共通の decorationCandidates() → sortDecorationCandidates() を使用。
- 同Lvの名称比較は Intl.Collator('ja-JP', {numeric:true, sensitivity:'base'}) で統一。
- duplicate な候補生成処理を作らない。

検証：
- JavaScript全scriptブロックを Node.js --check で構文確認。
- Lv3→Lv2→Lv1、その各Lv内50音順になることをサンプルデータで確認。
- 防具用と武器用の kind フィルタを確認。
- スロットLv以下のみ候補になることを確認。


【防御力検証 v4.23】
- MHDB APIの defense.max は限界突破前の最大強化値のため、そのまま使用するとシュバルカγが68→88（合計440）になっていた。
- 限界突破後の最大値はレア度別に base +54(R5) / +42(R6) / +30(R7) / +26(R8) として算出。シュバルカγは68→94、5部位で470。
- 武器の defenseBonus も総防御力へ加算。防御+1の武器なら470+1=471となる。
- 限界突破直後・Lv1はbase値を基準にすればシュバルカγ 68×5=340、武器防御+1なら341。

追加検証：ゲーム内の防御力は防具合計にハンター本体の基礎防御力1が加算されるため、シュバルカγ5部位はLv1で340+1=341、限界突破後最大で470+1=471となる。


【シリーズ／グループスキル検証 v4.23】
- 巨戟アーティアに付与したシリーズ／グループスキルは、武器を1部位として発動条件を判定。
- 例：巨戟アーティア「黒蝕竜の力」＋ゴア防具3部位 → 合計4部位として「黒蝕一体Ⅱ」を発動。
- シリーズ／グループスキル本体の名前ではなく、発動したランクの実スキル（例：黒蝕一体）をStep 4へ加算。
- 防具・武器データにシリーズ／グループスキルが直接含まれていても、装備部位数の条件を満たすまでは直接発動扱いにしない。
- アーティアで選択したシリーズスキルはシリーズ欄、グループスキルはグループ欄へ表示し、選択枠とDBのkindが食い違っても表示先が逆転しないようにした。
