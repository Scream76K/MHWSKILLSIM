MH Wilds ビルド＆火力シミュレーター v6.0.0

【V6.0 大規模構造整理】
- データ、Build State、コンボ状態、計算状態を App.state に集約。
- App.data / App.build / App.combo / App.regression を導入し、責務を明確化。
- 武器選択・防具選択を共通State API経由に変更。
- Step 5のコンボ状態を独立管理し、DPS計算がDOMの入力構造に直接依存しない形へ整理。
- 比較用DPS計算の旧 .cmv / .ctime 依存を修正し、技データ(mvs/time)を正しく参照。
- データキャッシュをv6用へ分離。旧v5キャッシュは自動移行読み込み。
- 主要データ取得後にV6構造回帰チェックを表示。
- v5系で残っていた未使用の装飾品管理・配置監査関数を整理。
- AI送信用データのバージョンをApp.versionから取得。

【設計方針】
- UI → State → Normalized Data → Engine → Result の責務分離を基本とする。
- 新機能は原則として既存のDOMを直接参照せず、State/APIを介して実装する。
- 武器種などの正規化はデータ層で一度だけ行い、各機能が生データを個別解釈しない。
- V6以降は新機能追加前に回帰チェックを行い、既存機能を壊さないことを優先する。
