MH Wilds スキルシミュレータ v6.2.7

■ 重要方針
MHDB公式データを正とし、武器種の推論・再分類を行わない。
武器種はMHDB公式APIのトップレベル kind と、公式の kind フィルタ結果のみを使用する。

■ 武器選択を再構築
- 14武器種それぞれについて /weapons?q={"kind":"..."} を使用。
- APIから返った武器を kind 別バケットへ直接保存。
- 武器選択UIは、現在選択中のkindに対応する公式APIバケットだけを表示。
- 全武器DBからのローカル推論フィルタを廃止。
- weaponType / type / category / class 等から武器種を推測しない。
- 公式kindと異なる武器は選択処理でも拒否。
- 取得時にレスポンス内のkindを全件検証し、1件でも不一致なら取得失敗として扱う。
- 旧版の武器キャッシュを使用しない。v6.2.7では武器を公式APIから再取得する。
- 武器一覧表示に API kind と一致検証結果（OK/NG）を表示。
