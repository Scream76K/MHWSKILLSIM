MH Wilds スキルシミュレータ v6.2.5

【重点修正】
・武器種「双剣」を選択しても大剣が表示される問題を対策。
・武器種フィルタは、正規化済みのトップレベル `kind` の完全一致だけで判定する方式へ変更。
・weaponType / type / category 等の推測値を武器種フィルタで再解釈しないようにした。
・武器種セレクタ／武器セレクタのイベント経路を、v5.21.3で実績のあるDOM onchange方式へ戻した。
・iOS Safari向けにoninput + setTimeoutで選択確定後の値を再同期。
・武器種変更時に武器selectを一旦空にしてから、選択中の武器種だけで一覧を再構築。
・武器選択時はDB → Build State → App.state.buildを同期する既存ブリッジを維持。
・データキャッシュをv6.2.5へ更新し、v6.2.4キャッシュを旧キャッシュとして扱う。
・ビルド保存キーをv6.2.5へ更新し、v6.2.4以前の保存データを移行対象に追加。

【検証】
・App.version / title / visible VERSION を6.2.5へ統一。
・JS構文チェックを実施。
・ZIP整合性チェックを実施。
・武器種フィルタの静的回帰条件を追加。
